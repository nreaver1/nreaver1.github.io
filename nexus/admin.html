Campaign Snapshot
Export a complete backup of all campaign data — party members, treasury ledger, currencies, loot items, and settings — as a single JSON file. Restore from a snapshot to replace all data in one operation. Restore requires confirmation and cannot be undone.
Export Everything
Downloads a full snapshot of all 8 tables as one JSON file (party, treasury, loot, session log, NPCs, and settings).
Restore from Snapshot
Replaces all data from a previously exported snapshot file.
Admin Password
Change the admin password used across the whole site — this gate, the site-wide read-only lock below, and every "admin required" prompt on other pages. It's stored as a SHA-256 hash in js/nexus-config.js — update that file after changing it here, or the new password only persists for this browser tab.
⚠  To make a password change permanent: after clicking Update, copy the hash shown below into js/nexus-config.js as the value of NEXUS_ADMIN_HASH.
Danger Zone
Permanently delete all data from a module. These actions cannot be undone. Each button requires a confirmation before anything is deleted.
